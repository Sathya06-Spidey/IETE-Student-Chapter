IETE STUDENT CHAPTER WEBSITE – SRM CHENNAI RAMAPURAM
====================================================

This is a static HTML/CSS/JavaScript website and can be opened locally or hosted on GitHub Pages, Netlify, Vercel, or any normal web server.

FILES
-----
index.html          Home page
about.html          SRM information
about-iete.html     IETE information
 events.html        Events
projects.html       Student projects
team.html           Team / office bearers
gallery.html        Gallery
contact.html        Contact form
css/style.css       Responsive design and animations
js/script.js        Mobile navigation and form behavior
images/             Logos and website images

IMPORTANT BEFORE PUBLISHING
----------------------------
1. Replace the placeholder email and Instagram handle in contact.html.
2. Replace the temporary team.png images in team.html with the actual team member photos using the same filenames or update the image paths.
3. Replace the sample member/event/project counts on index.html with verified chapter data.
4. Connect the contact form to an email/form service if you want messages to be delivered.
5. Add real event and project cards as activities are announced.

LOCAL TESTING
-------------
Open index.html in a browser. For the best experience, run a local server from this folder, for example in VS Code using the Live Server extension.

HOSTING
-------
GitHub Pages: upload the IETE-Website folder to a GitHub repository and enable Pages from the repository settings.
Netlify: drag the IETE-Website folder into Netlify's deploy area.
Vercel: import the folder/repository as a static site.
